# GeoNeuronX — a dynamical neuron abstraction

**History becomes state. Geometry shapes that state. Local nonlinearities compute on it. Local learning divides the temporal world. The AIS turns the result into an event stream.**

GeoNeuronX is a falsification-first restart of the Geometric Neuron lineage after the Saturday/Sunday/Monday/Tuesday work on state, persistent operators, ICA/IVA/IVE, AMUSE/SOBI, and hard digital attackers.

The object being tested is now explicit:

> **Can a neuron-like unit be treated as a dynamical computer whose own internal tempo-spatial state converts recent input history into simultaneous local coordinates, performs nonlinear computation before those coordinates collapse at the soma, learns useful temporal projections with local-ish rules and population competition, and then compresses the result into a regulated outgoing event stream?**

That is the candidate **dynamical neuron**.

It is an abstraction in the same sense that McCulloch-Pitts was an abstraction. It is not a claim that real dendrites literally implement Takens, AMUSE, SOBI, Oja, or any exact equation in this repo.

# The computational primitive

McCulloch-Pitts preserves roughly:

```text
weighted present inputs
        ↓
     threshold
        ↓
     output bit
```

or

```text
y(t) = H(w^T x(t) - theta)
```

GeoNeuronX preserves a different set of features:

```text
TEMPORAL INPUT / SYNAPTIC MIXTURES
                ↓
        DENDRITIC DYNAMICS
  path-dependent filtering / state
                ↓
      SIMULTANEOUS BRANCH STATE
                ↓
      LOCAL NONLINEAR SUBUNITS
                ↓
      LOCAL / POPULATION LEARNING
 self-normalization + competition
                ↓
       SOMA INTEGRATION
                ↓
              AIS
     adaptive event bottleneck
                ↓
              AXON
        narrow event stream
                ↓
       large downstream fan-out
```

A compact single-unit form is:

```text
r_j(t) = (h_j * x)(t)
u_j(t) = phi_j(r_j(t))
z(t)   = sum_j w_j u_j(t)
y(t)   = AIS(z(t), slow_homeostatic_state)
```

where morphology changes the family of temporal filters `h_j`.

The crucial difference from a static artificial neuron is:

> **the coordinates presented to the learned weights are generated by the unit's own dynamics.**

The matrix `W` is still useful notation. It is no longer the conceptual center. The center is the **tempo-spatial state** that supplies the coordinates on which `W`, Oja-like rules, competition, or other learners operate.

# Why this became worth testing

## Aizenbud et al. 2026 — morphology changes single-neuron I/O complexity

Aizenbud et al. measure how difficult detailed cortical neuron models are to emulate with a fixed temporal convolutional network. Human neurons are harder to mimic than rat neurons. Total dendritic area is a strong predictor of functional complexity; longest bifurcation branch also carries substantial predictive power; area plus longest bifurcation branch predicts more still.

Their interpretation emphasizes extended dendritic trees, electrical compartmentalization, semi-independent dendritic subunits, and stronger NMDA-mediated nonlinearities.

GeoNeuronX asks a narrower mechanistic question that their paper does not answer:

> **What computational value can the allocation of path length buy?**

Working hypothesis:

```text
morphological allocation
        ↓
transfer-function diversity
        ↓
history distributed into branch state
        ↓
local nonlinear temporal features
```

That is our hypothesis, not theirs.

## AMUSE / SOBI — hidden processes can be identified by their relation to the past

AMUSE whitens a multivariate stream and diagonalizes one lagged covariance matrix. SOBI jointly uses several lags.

The lesson imported here is not “AMUSE is the neuron.” It is:

> **different dynamical causes can be distinguishable because they relate differently to their own past.**

That gives a precise job to a physical system that naturally exposes differently filtered histories.

## Oja / generalized Hebbian learning — adaptation can act on state already produced by dynamics

Oja's rule is a PCA-like local learning abstraction:

```text
y = w^T x
Delta w = eta y (x - y w)
```

Oja does not create temporal memory. But if its inputs are branch states that already contain filtered history, a memoryless weight update can learn over temporal features.

Gate 5 extends that idea with Sanger's generalized Hebbian algorithm: Oja-like self-normalization plus lateral competition so several outputs do not all learn the same strongest direction.

## AIS — adaptive boundary between rich internal state and narrow output

The axon initial segment initiates and shapes action potentials and exhibits activity-dependent plasticity. In the abstraction it is the output governor:

```text
rich dendritic / somatic analog state
              ↓
             AIS
      adaptive excitability
              ↓
       narrow event stream
```

The axon then fans that event stream out to many different downstream dynamical units.

So the neuron has an hourglass structure:

```text
massive fan-in
     ↓
rich local dynamics
     ↓
narrow AIS event channel
     ↓
massive fan-out
```

# Gate 0 — length changes temporal transfer

`experiments/gate0_length_is_memory.py`

The first toy held total path-length budget fixed while redistributing path lengths under a hand-written delayed/attenuated transfer law.

Equal paths produced a redundant observation basis. Diverse paths produced a better-conditioned one and AMUSE recovered temporally distinct sources much more successfully.

A random digital matrix did equally well or better.

Surviving claim:

> geometry can physically instantiate a useful temporal basis; it is not superior merely because it is geometry.

# Gate 1 — AIS as adaptive neck

`experiments/gate1_ais_homeostasis.py`

A scalar effective AIS threshold adapts to output-rate error. Across a 4x change in upstream drive, a fixed threshold changes firing dramatically while the adaptive threshold keeps event rate near its target.

This is only a functional abstraction of excitability homeostasis.

Surviving claim:

> rich upstream computation and the outgoing event budget can be controlled by different mechanisms.

# Gate 2 — passive cable, fixed material

`experiments/gate2_passive_cable_geometry.py`

Gate 2 deletes the hand-written transfer law and uses a passive compartmental cable:

```text
C dV/dt = -G V + I
```

Across morphologies it holds fixed topology, branch count, diameter, compartment count, passive membrane parameters, **total dendritic cable length = 840 µm**, and therefore total dendritic area. Only allocation changes.

For narrow-band 2 / 20 / 100 Hz sources:

```text
AMUSE recovery       0.7356 -> 0.8666
linear oracle corr   0.7848 -> 0.8810
```

For broad AR(1) sources the same morphology change does not help. A seven-state digital RC bank beats the cable.

Surviving claim:

> **fixed material can be redistributed into geometry that exposes a more useful temporal basis for some source classes.**

# Gate 3 — geometry materializes history into space

`experiments/gate3_distributed_synapses.py`

The drive moves to distal synapses. Every tree has the same total `840 µm` cable, area, branch count, synapses, and **exactly 360 µm soma-to-leaf path length**. Only the location of cable relative to branch points changes.

As internal bifurcation allocation grows from `40 -> 210 µm`:

```text
bifurcation AMUSE       0.5730 -> 0.8592
bifurcation static      0.7293 -> 0.8748
trunk static            0.7440 -> 0.6863
```

Length does not simply make the whole neuron better. It redistributes **where temporal information is instantaneously accessible**.

Then the attacker: give the reader an explicit digital delay line and almost every region reaches about `0.96` recovery, including the one-dimensional soma trace.

So the tree does not create information unavailable in input history. It converts some of that history into simultaneous spatial state:

```text
history in time
      ↓
physical cable dynamics
      ↓
state distributed in space
```

# Gate 4 — the dynamical neuron computes a nonlinear temporal relation

`experiments/gate4_dynamical_neuron.py`

The task is delayed XOR:

```text
+1 if sign(x[t]) != sign(x[t - 16 ms])
-1 otherwise
```

A linear filter can possess the relevant history and still cannot solve XOR with a linear readout.

Five-seed development accuracy:

| bifurcation allocation | soma linear | soma nonlinear | branch linear | **branch-local nonlinear** | FIR linear | **FIR quadratic** |
|---:|---:|---:|---:|---:|---:|---:|
| 40 µm  | 0.4986 | 0.5115 | 0.5008 | **0.5792** | 0.4990 | **1.0000** |
| 120 µm | 0.4984 | 0.5104 | 0.5012 | **0.5849** | 0.4990 | **1.0000** |
| 210 µm | 0.4980 | 0.5094 | 0.5015 | **0.5935** | 0.4990 | **1.0000** |

What survives:

1. state/history alone is not enough for a nonlinear temporal relation;
2. a nonlinearity only after soma collapse barely helps;
3. local nonlinearities acting on different history-bearing branch states do help;
4. geometry modulates that nonlinear feature map;
5. an ordinary quadratic digital delay map destroys the task and remains the winner.

Gate 4 earns the phrase:

> **dynamical neuron = stateful temporal feature generator + local nonlinear computation + output integration.**

# Gate 5 — a population learns different temporal listeners

`experiments/gate5_population_specialization.py`

Gate 5 removes source labels from the learning rule and asks whether several outputs receiving the same branch-state trajectory can specialize.

The bridge is deliberately simple. First whiten the branch state `q(t)`; then form:

```text
u(t) = [q(t) + q(t-tau)] / sqrt(2)
```

For whitened `q`:

```text
Cov[u] = I + C_tau_sym
```

so `u` has the same eigenvectors as the symmetrized AMUSE lag covariance. We can therefore hand `u(t)` to ordinary Oja/Sanger-style online learning.

This is not a biological claim. It is a mathematical bridge from **lagged source identification** to **generalized Hebbian population learning**.

Five-seed development result:

| bifurcation allocation | independent Oja recovery | Oja duplication | **temporal Sanger recovery** | Sanger duplication | shuffled-time recovery | zero-lag Sanger | batch AMUSE |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 40 µm  | 0.3330 | 0.9996 | **0.7705** | 0.0139 | 0.6869 | 0.6654 | 0.7911 |
| 120 µm | 0.3293 | 0.9999 | **0.8004** | 0.0111 | 0.7272 | 0.7461 | 0.8055 |
| 210 µm | 0.3311 | 0.9996 | **0.8440** | 0.0129 | 0.7622 | 0.7811 | 0.8479 |

The story is clean:

```text
three independent Oja units
        ↓
all learn essentially the same thing
output duplication ≈ 1.0

add generalized Hebbian / lateral competition
        ↓
three distinct outputs
output duplication ≈ 0.01
source recovery ≈ 0.84
```

At `210 µm`, online temporal Sanger reaches `0.8440` versus `0.8479` for batch AMUSE.

Time-shuffling the past drops recovery to `0.7622`, so the lag relation itself contributes useful identity. Zero-lag competition also trails the temporal rule.

And geometry still matters: temporal population recovery rises `0.7705 -> 0.8440` as the fixed cable budget moves into longer internal bifurcation sections.

The important caveat is explicit: **whitening is still batch/global in Gate 5.** The Sanger stage is online, but the end-to-end local story is not complete until whitening/decorrelation is made streaming and local enough.

Surviving claim:

> **given normalized dynamical branch-state coordinates, Oja-like learning plus lateral competition can specialize a population into different temporal processes using the same lag structure exploited by AMUSE.**

Full note: `results/GATE5.md`.

## Gate 8 — axonal fan-out
